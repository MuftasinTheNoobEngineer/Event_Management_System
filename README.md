# Event Management System

A web-based Event Management System designed to simplify event planning, management, and coordination through an organized and user-friendly platform.

## 📌 Project Overview

The Event Management System provides a centralized platform for managing events, users, schedules, venues, tickets, and other event-related activities.

The system is designed to make event organization more efficient by providing different functionalities for users and administrators.

## ✨ Key Features

- User registration and authentication
- User profile management
- Event creation and management
- Event browsing and details
- Venue management
- Ticket management
- User request and role management
- Dashboard for managing system activities
- Database integration
- Responsive web interface

## 🛠️ Technologies Used

- Next.js
- TypeScript
- React
- Tailwind CSS
- Node.js
- Database Management System
- Git & GitHub
